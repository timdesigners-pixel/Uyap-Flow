UYAP Flow 2.3.8

ZIP archives now include a Mind Palace manifest, case metadata and SHA-256 checksums for each document. Existing PDF/UDF download modes remain available. Import the ZIP through Mind Palace 1.3 to copy documents into its local store and link them to the corresponding case or enforcement record.

A valid, authorized UYAP browser session is still required. Live UYAP access was not exercised by automated tests.
